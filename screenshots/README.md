# Deployment Screenshots

These screenshots document the completed Azure deployment and API verification.

## Privacy redactions applied

The GitHub-ready copies intentionally blur:

- Azure account email and organization identifiers
- Azure subscription ID
- Public IP addresses shown in browser bars or Azure VM pages
- Browser status URLs containing subscription paths

The following remain visible because they are useful architectural evidence and are not authentication secrets:

- Resource group and VM names
- VNet and subnet names
- Private IP addresses used between application tiers
- API responses and deployment status

Never publish screenshots containing passwords, access keys, connection strings, tokens, private SSH keys, or unredacted cloud credentials.
